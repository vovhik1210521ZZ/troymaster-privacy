# Политика конфиденциальности — приложение «СтройМастер»

> Текст готов к публикации на любом хостинге (GitHub Pages, Google Sites и т.п.).
> **RuStore требует URL политики** при публикации, а не только файл внутри приложения.
> Внутри приложения используется копия: `app/src/main/res/raw/privacy_policy.txt`.

## Как получить URL (варианты)
1. **GitHub Pages:** создать публичный репозиторий, положить этот файл как `index.html`/`index.md`,
   включить Pages → URL вида `https://<логин>.github.io/<репозиторий>/`.
2. **Google Sites:** создать страницу, вставить текст, «Опубликовать» → получить URL.
3. Любой статический хостинг (Netlify, Vercel, свой домен).

Полученный URL указать в RuStore Console в поле «Политика конфиденциальности».

## Текст политики

**Дата последнего обновления: 15.10.2026**

1. Приложение «СтройМастер» выполняет расчёты, а также хранит сметы, проекты и справочные данные
   **локально на устройстве пользователя**. Разработчик не собирает и не передаёт персональные данные
   на свои серверы.

2. Приложение не запрашивает доступ к файлам, контактам, геолокации и камере.

3. **Реклама.** Приложение использует Yandex Mobile Ads SDK и медиацию VK Ads (myTarget) для показа
   рекламы. Рекламные SDK могут собирать рекламный идентификатор устройства (GAID) и обезличенную
   техническую информацию для подбора и показа рекламы, в соответствии с политиками соответствующих
   сервисов. Реклама показывается только при наличии подключения к сети; без сети приложение работает
   в полном объёме (расчёты, сметы, справочник, экспорт PDF).

4. **Согласие на рекламу.** При первом запуске приложение предлагает выбор: согласие на показ рекламы
   либо показ без персонализации. Выбор хранится только на устройстве.

5. В текущей версии приложения **нет покупок и подписок** — все калькуляторы бесплатны, платёжные данные
   не запрашиваются и не обрабатываются.

6. **Данные пользователя.** Сметы, проекты, свои цены, история и настройки хранятся на устройстве и
   удаляются вместе с приложением либо через пункт «Сбросить все данные» в настройках.

7. Приложение не предназначено для детей младше 12 лет. Возрастная маркировка — 12+.

8. **Контакты:** developer@stroymaster.ru *(заменить перед публикацией)*.

## Связь с внутренней политикой
Текст в приложении (`res/raw/privacy_policy.txt`) должен совпадать по смыслу с этой публикацией.
При изменении — обновить оба места.
