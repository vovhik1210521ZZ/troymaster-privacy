Политика конфиденциальности — приложение «СтройМастер»
Дата последнего обновления: 15.10.2026

1. Общие положения
1.1. Настоящая Политика конфиденциальности описывает, какие данные собирает мобильное приложение «СтройМастер» (далее — Приложение), как они используются и защищаются.

1.2. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

2. Какие данные мы собираем
2.1. Данные, которые хранятся только на устройстве:

Сметы, проекты, расчёты, сохранённые цены, история
Настройки приложения (тема, единицы измерения)
Разблокированные калькуляторы
Эти данные не передаются на серверы разработчика и не покидают ваше устройство.

2.2. Данные, которые собираются автоматически (через рекламные SDK):

Рекламный идентификатор устройства (GAID)
Техническая информация: модель устройства, версия Android, язык системы
Данные о взаимодействии с рекламой (показы, клики)
Приложение НЕ запрашивает доступ к файлам, контактам, геолокации и камере.

3. Реклама
3.1. Приложение использует Yandex Mobile Ads SDK и медиацию VK Ads (myTarget) для показа рекламы. Рекламные SDK могут собирать данные, указанные в п. 2.2.

3.2. Реклама показывается только при наличии подключения к сети. Без подключения Приложение работает в полном объёме.

3.3. Для персонализации рекламы используются обезличенные данные. Вы можете отключить персонализацию в настройках Android.

4. Передача данных третьим лицам
4.1. Разработчик не передаёт ваши данные третьим лицам, кроме рекламных SDK, указанных в п. 3.1.

4.2. Рекламные SDK работают в соответствии с собственными политиками конфиденциальности:

Yandex Mobile Ads: https://yandex.ru/legal/confidential/
VK Ads (myTarget): https://ads.vk.com/ru/legal
5. Хранение и защита данных
5.1. Данные пользователя (сметы, проекты) хранятся локально и защищены средствами операционной системы Android.

5.2. Рекламные SDK хранят данные в соответствии со своими политиками.

6. Права пользователя
6.1. Вы можете в любой момент:

Удалить все данные через «Настройки → Сбросить все данные»
Отключить показ персонализированной рекламы в настройках Android
Удалить Приложение — все локальные данные будут удалены автоматически
7. Дети
7.1. Приложение имеет возрастную маркировку 12+.

7.2. Мы не собираем сознательно данные детей младше 12 лет.

8. Изменения в Политике
8.1. Разработчик может обновлять настоящую Политику. Актуальная версия всегда доступна по этому адресу.
