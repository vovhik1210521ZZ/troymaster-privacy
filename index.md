Политика конфиденциальности приложения «СтройМастер»
Дата последнего обновления: 02.11.2026

1. Общие положения
1.1. Настоящая Политика описывает, какие данные собирает приложение «СтройМастер», как они используются, хранятся и защищаются.

1.2. Оператор обработки данных — Новиков Владимир (самозанятый), контакт: ya.novik26@yandex.ru.

1.3. Используя Приложение, вы соглашаетесь с настоящей Политикой. Согласие на обработку рекламных данных запрашивается отдельно при первом запуске.

2. Какие данные мы собираем
2.1. Данные, которые хранятся только на устройстве:

сметы, проекты, расчёты, сохранённые цены и история;
настройки приложения (тема, единицы измерения);
разблокированные калькуляторы.
Эти данные не передаются на серверы разработчика и не покидают устройство.

2.2. Данные, которые собираются автоматически через рекламные SDK:

рекламный идентификатор устройства (GAID);
техническая информация: модель устройства, версия Android, язык системы;
данные о взаимодействии с рекламой (показы, клики).
Приложение не запрашивает доступ к контактам, геолокации, камере и микрофону. Постоянный доступ к файлам также не запрашивается: при экспорте PDF/CSV пользователь сам выбирает файл через системный диалог Android.

3. Реклама
3.1. Приложение использует Yandex Mobile Ads SDK и медиацию VK Ads (myTarget). Эти SDK могут собирать данные, указанные в п. 2.2.

3.2. Реклама показывается только при наличии подключения к сети. Без сети расчёты, сметы, проекты, справочник и экспорт работают в полном объёме.

3.3. Данные из п. 2.2 используются для показа и персонализации рекламы. При первом запуске можно выбрать показ без персонализации; выбор хранится на устройстве. Персонализацию также можно отключить в настройках Android.

4. Передача данных
4.1. Разработчик не передаёт данные третьим лицам, кроме рекламных SDK, указанных в п. 3.1. Данные не продаются.

4.2. Рекламные SDK работают в соответствии со своими политиками:

Yandex Mobile Ads: https://yandex.ru/legal/confidential/
VK Ads (myTarget): https://ads.vk.com/ru/legal
5. Хранение и защита
5.1. Сметы, проекты и настройки хранятся локально и защищены средствами операционной системы Android.

5.2. Локальные данные хранятся до удаления приложения или сброса данных. Рекламные SDK хранят данные в соответствии со своими политиками.

5.3. Облачный бэкап приложения отключён: данные смет и проектов не передаются в Google Backup.

6. Права пользователя
6.1. Вы можете в любой момент:

удалить все данные через «Настройки → Сбросить все данные»;
отключить персонализацию рекламы в настройках Android;
удалить приложение — локальные данные будут удалены автоматически.
7. Дети
7.1. Приложение имеет возрастную маркировку 16+.

7.2. Мы не собираем сознательно данные детей младше 16 лет.
