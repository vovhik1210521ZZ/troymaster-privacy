  <h1>Политика конфиденциальности приложения «СтройМастер»</h1>
  <p><strong>Дата последнего обновления:</strong> 02.11.2026</p>

  <h2>1. Общие положения</h2>
  <p>1.1. Настоящая Политика описывает, какие данные собирает приложение «СтройМастер», как они используются, хранятся и защищаются.</p>
  <p>1.2. Оператор обработки данных — Новиков Владимир (самозанятый), контакт: <a href="mailto:ya.novik26@yandex.ru">ya.novik26@yandex.ru</a>.</p>
  <p>1.3. Используя Приложение, вы соглашаетесь с настоящей Политикой. Согласие на обработку рекламных данных запрашивается отдельно при первом запуске.</p>

  <h2>2. Какие данные мы собираем</h2>
  <p>2.1. Данные, которые хранятся только на устройстве:</p>
  <ul>
    <li>сметы, проекты, расчёты, сохранённые цены и история;</li>
    <li>настройки приложения (тема, единицы измерения);</li>
    <li>разблокированные калькуляторы.</li>
  </ul>
  <p>Эти данные не передаются на серверы разработчика и не покидают устройство.</p>

  <p>2.2. Данные, которые собираются автоматически через рекламные SDK:</p>
  <ul>
    <li>рекламный идентификатор устройства (GAID);</li>
    <li>техническая информация: модель устройства, версия Android, язык системы;</li>
    <li>данные о взаимодействии с рекламой (показы, клики).</li>
  </ul>
  <p>Приложение не запрашивает доступ к контактам, геолокации, камере и микрофону. Постоянный доступ к файлам также не запрашивается: при экспорте PDF/CSV пользователь сам выбирает файл через системный диалог Android.</p>

  <h2>3. Реклама</h2>
  <p>3.1. Приложение использует Yandex Mobile Ads SDK и медиацию VK Ads (myTarget). Эти SDK могут собирать данные, указанные в п. 2.2.</p>
  <p>3.2. Реклама показывается только при наличии подключения к сети. Без сети расчёты, сметы, проекты, справочник и экспорт работают в полном объёме.</p>
  <p>3.3. Данные из п. 2.2 используются для показа и персонализации рекламы. При первом запуске можно выбрать показ без персонализации; выбор хранится на устройстве. Персонализацию также можно отключить в настройках Android.</p>

  <h2>4. Передача данных</h2>
  <p>4.1. Разработчик не передаёт данные третьим лицам, кроме рекламных SDK, указанных в п. 3.1. Данные не продаются.</p>
  <p>4.2. Рекламные SDK работают в соответствии со своими политиками:</p>
  <ul>
    <li>Yandex Mobile Ads: <a href="https://yandex.ru/legal/confidential/">https://yandex.ru/legal/confidential/</a></li>
    <li>VK Ads (myTarget): <a href="https://ads.vk.com/ru/legal">https://ads.vk.com/ru/legal</a></li>
  </ul>

  <h2>5. Хранение и защита</h2>
  <p>5.1. Сметы, проекты и настройки хранятся локально и защищены средствами операционной системы Android.</p>
  <p>5.2. Локальные данные хранятся до удаления приложения или сброса данных. Рекламные SDK хранят данные в соответствии со своими политиками.</p>
  <p>5.3. Облачный бэкап приложения отключён: данные смет и проектов не передаются в Google Backup.</p>

  <h2>6. Права пользователя</h2>
  <p>6.1. Вы можете в любой момент:</p>
  <ul>
    <li>удалить все данные через «Настройки → Сбросить все данные»;</li>
    <li>отключить персонализацию рекламы в настройках Android;</li>
    <li>удалить приложение — локальные данные будут удалены автоматически.</li>
  </ul>

  <h2>7. Дети</h2>
  <p>7.1. Приложение имеет возрастную маркировку 16+.</p>
  <p>7.2. Мы не собираем сознательно данные детей младше 16 лет.</p>

  <h2>8. Изменения политики</h2>
  <p>8.1. Разработчик может обновлять Политику. Актуальная версия всегда доступна по адресу ниже.</p>
